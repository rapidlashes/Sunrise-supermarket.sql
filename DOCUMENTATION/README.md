## WHAT IS INCLUDED ##


**SECTION A** : **CREATING SCHEMAS AND TABLES**

This section covers the Data Definition Language in SQL. Focuses on creating schemas, setting search path, creating tables and also inserting values in those tables. It defines the types of data/values to be input in the table eg, `INT()`, `DECIMAL()`, `VARCHAR()`, `TXT()`, `SERIAL()` etc. It also defines constrains along side those values eg `UNIQUE()`, `DEFAULT()`, `NOT NULL()`, `NULL()`, `PRIMARY KEY()`, `FOREIGN KEY()` etc.





**SECTION B** : **ALTERING AND CHANGING TABLES/VALUES**

The section covers Data Manipulation Language in SQL. It focuses on changing values on the tables, altering the table structure by adding new columns or deleting existing columns. Common SQL key words used  here are `select()`, `WHERE()`, `ORDER BY()`, `GROUP BY()`, `HAVING()`, `LIMIT()` etc.



**SECTION C** : **FILTERING AND OPERATIONS**

This section focuses mainly on the different SQL operators like Comparison operators, Logical Operators, Range operators, Membership operators and Pattern matching. Common Keywords are `IN()`, `NOT IN()`, `AND()`, `OR()`, `BETWEEN()`, `>`, `<` ,`=`, `LIKE()`, `ILIKE()` etc.



**SECTION D**: **GROUPING AND AGGREGATES**

This section is montly on the use of functions in SQL. Common fuctions used here are `SUM()`, `COUINT()` and `AVG()`.


**SECTION E : JOINS**

This section focuses on Joins which fall under the Data Querry Language. The joins mostly used here are `inner join()` and `left join()`.


**NOTE**: each section is on it's separate SQL script
